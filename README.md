# Duelo de Sílabas

Juego para que niños aprendan a leer y escribir en español:

- Escuchan una sílaba y la arrastran al dibujo que empieza con ella (3 oportunidades por palabra).
- Arman la palabra completa con sílabas revueltas.
- Trazan la sílaba con el dedo sobre doble raya.
- Cada acierto destapa una pieza de un rompecabezas; al terminar eligen premio (gato o memorama).
- 90 palabras en 3 niveles, perfiles por niño y reporte para papás.

Es una sola página estática (`index.html`), sin servidor. El progreso se guarda en el navegador de cada dispositivo.
El modo en línea entre dos tabletas solo funciona dentro de Claude; en esta versión aparece como no disponible.

Voces generadas con [Piper](https://github.com/rhasspy/piper): es_MX-claude-high (Apache-2.0), es_MX-ald-medium (dominio público) y es_AR-daniela-high, entrenado con OpenSLR 61 (CC BY-SA 4.0).
